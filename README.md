## 🤖 Как работает AI

- Используется локальный сервер **Ollama**  
- Модель: `gemma3:12b`  
- Запросы отправляются на:
```
http://localhost:11434/api/generate
```
- Тайм-аут запроса: 120 секунд  
- Ответ используется без стриминга  
- Все ответы формируются по строгим системным промптам  

Бот поддерживает несколько режимов работы:
- подбор темы по запросу  
- доработка темы  
- генерация темы (быстрая / по параметрам)  
- генерация разделов проекта

## ⚙️ Установка и запуск

### 1️⃣ Клонирование репозитория
```
git clone https://github.com/chasingthedreams/ProjectHelper.git
cd ProjectHelper
```

---

### 2️⃣ Создание файла `.env`

Создайте файл `.env` в корне проекта:
```env
TOKEN=YOUR_TELEGRAM_BOT_TOKEN
```
Получить токен можно через: 👉 https://t.me/BotFather

### 3️⃣ Установка Ollama

Установите Ollama:
https://ollama.com

После установки загрузите модель:

```bash
ollama pull gemma3:12b
```
### 4️⃣ Установка зависимостей
```
pip install pyTelegramBotAPI requests python-dotenv
```

### 5️⃣ Запуск
```
python main.py
```
Бот запускается через:
```
if __name__ == "__main__":
    bot.polling(none_stop=True)
```
